# Platform logos for the hero "We build on" row

Drop the official artwork here, from each owner's brand or press kit, then
set `logo` (and `logoWidth` at 24px tall) for that entry in
components/enterprise/HeroSection.tsx. Files are shown in one light tone.

| File | Source |
| --- | --- |
| aws.svg | AWS trademark guidelines and "Powered by AWS" artwork (aws.amazon.com/trademark-guidelines) |
| microsoft-azure.svg | Microsoft trademark and brand guidelines (microsoft.com/legal/intellectualproperty/trademarks) |
| google-cloud.svg | Google Cloud brand resources / partner marketing guidelines |
| claude.svg | Anthropic brand / press materials (anthropic.com) |
| openai.svg | OpenAI brand guidelines (openai.com/brand) |

Read each guideline before publishing: some allow a logo only to show
compatibility, and some require partner status or written permission.
